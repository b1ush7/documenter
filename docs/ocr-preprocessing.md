# OCR 图片预处理

PDF 扫描页、PNG 和 JPEG 共用确定性预处理流程，只作用于发送 OCR 的工作副本，不覆盖源文件、不创建文档版本。

调用 `POST /file/{fileId}/versions/{versionNo}/ocr` 或 `/ocr/text`，例如：

```json
{
  "language": "zh",
  "pages": [1],
  "rotationDegrees": 90,
  "enhance": true,
  "lowLight": true,
  "denoise": true,
  "sharpen": true,
  "region": {"x": 100, "y": 80, "width": 600, "height": 400}
}
```

所有开关默认 false，`rotationDegrees` 默认 0；省略 `region` 识别整图。先按原图或 PDF 实际渲染像素裁剪区域，再白底灰度化、可选 1%/99% 对比度拉伸、可选 Gamma 提亮、可选 3×3 中值去噪、可选轻度反差锐化，最后顺时针旋转。仅指定旋转时保留原始颜色和透明度；需要预处理透明图片时按白底合成。

旋转必须显式指定 0/90/180/270 度，其他角度返回 400；没有自动方向判断或任意角度倾斜校正。锐化适合轻度边缘发虚，不承诺恢复严重失焦或运动模糊。中值去噪可能抹除极细笔画，不应对所有图片默认启用；低照度增强也可能放大噪声，需按样本选择组合。

区域坐标始终相对原图。云端看到的是预处理后的图片，返回行和表格单元格框经逆旋转后，再加裁剪偏移，最终输出仍相对完整原图；90/270 度旋转不会交换响应页面的原始宽高。识别文本和表格逻辑行列沿用旋转后阅读顺序，不以原图中的横竖方向重新排序。`paragraphs` 仍是启发式分组，旋转页面以 `lines` 和 `tables` 为准。

未选择区域时，含原生文字的 PDF 页面仍优先返回 NATIVE，不渲染、不预处理、不调用云端。扫描页才渲染并处理；选择区域则按现有规则强制 OCR。现有页数、像素、DPI、上传字节及输出限制继续适用。云端缓存按实际 PNG 内容建立；新的预处理产物不会错误复用原图响应。

像素和接口回归：

```powershell
mvn -o test '-Dtest=OcrImagePreprocessorTest,OcrServiceImplTest,OcrControllerTest'
```

覆盖四种方向逐像素旋转与逆坐标、整图边界、表格跨度不变、区域偏移叠加、低照度亮度、透明白底、孤立噪声消除、软边缘锐化、原图不变和非法角度。测试使用确定性图片及 OCR 替身，不证明具体云供应商的中文识别准确率；真实模型预处理前后准确率仍需供应商和业务样本验收。
